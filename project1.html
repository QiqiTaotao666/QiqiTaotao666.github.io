📋 项目介绍

这个水体系统是我为实时渲染项目开发的可复用技术方案。它基于物理的Gerstner波算法，能够模拟真实的海洋和湖泊效果。系统高度模块化，可以轻松集成到任何Unreal Engine项目中。

✨ 核心特性

🌊 Gerstner波浪

多层叠加的程序化波浪，支持方向、速度、振幅、波长的精确控制

💎 PBR材质

基于物理的水体材质，真实的菲涅尔反射、折射和次表面散射

☀️ 动态焦散

实时计算的水下焦散效果，随光照和波浪动态变化

🫧 泡沫系统

基于波峰和岸边距离的程序化泡沫生成，使用Niagara粒子增强细节

🎨 深度混合

浅水深水颜色过渡，水岸边缘的柔和混合

⚡ 性能优化

LOD系统、视锥裁剪、可配置质量级别，支持移动平台

🛠️ 技术实现

  • 波浪模拟：在Material中实现Gerstner波算法，通过顶点偏移实现波浪起伏
  • 法线计算：程序化计算波浪法线，保证光照和反射的正确性
  • 反射系统：使用Scene Capture 2D和平面反射相结合，优化性能
  • 折射效果：Scene Texture采样结合折射偏移，模拟水下物体扭曲
  • 焦散纹理：程序化生成焦散贴图，通过投影映射到水下表面
  • 泡沫生成：基于波浪高度和坡度判断，结合Noise纹理生成泡沫Mask
  • 交互系统：支持物体入水涟漪、浮力计算、水花粒子生成

💡 技术亮点

  • 真实物理：基于Gerstner波的精确模拟，而非简单的法线贴图动画
  • 高性能：通过LOD和质量分级，在移动端也能流畅运行（60fps+）
  • 易于使用：所有参数通过Material Instance暴露，美术可视化调节
  • 可扩展性：模块化设计，可以轻松添加新特性（如水下雾效、波浪交互等）
  • 通用性强：支持海洋、湖泊、河流、瀑布等多种水体类型

📊 代码示例

Gerstner波核心算法（HLSL）：

// Gerstner Wave Function float3 GerstnerWave(float2 Position, float Time, float4 Wave) { float Steepness = Wave.z; float Wavelength = Wave.w; float k = 2 * PI / Wavelength; float c = sqrt(9.8 / k); float2 d = normalize(Wave.xy); float f = k * (dot(d, Position) - c * Time); float a = Steepness / k; return float3( d.x * (a * cos(f)), a * sin(f), d.y * (a * cos(f)) ); }
