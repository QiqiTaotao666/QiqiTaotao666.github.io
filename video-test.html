❌ 文件过大错误

这个视频文件大小为 652 MB，远超 GitHub 的 100MB 文件大小限制。

解决方案：

  • 使用 HandBrake 或在线工具压缩视频到 < 50MB
  • 或使用 Git LFS (大文件存储)
  • 或将视频上传到 B站/YouTube 并嵌入链接

提示：网页视频建议分辨率 1080p，码率 2-4 Mbps，时长控制在 2-3 分钟以内。
