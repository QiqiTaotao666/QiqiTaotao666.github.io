🎥 Git LFS 视频播放解决方案

方案 1: 使用 GitHub Media URL（推荐）

GitHub 提供了特殊的 URL 来直接访问 LFS 文件内容：

<video controls> <source src="https://media.githubusercontent.com/media/用户名/仓库名/分支/path/to/video.mp4" type="video/mp4"> </video>

示例：

<video controls> <source src="https://media.githubusercontent.com/media/QiqiTaotao666/QiqiTaotao666.github.io/main/videos/bodian.mp4" type="video/mp4"> </video>
✅ 优点：
  • 直接从 GitHub LFS 服务器加载真实视频文件
  • 不需要修改 Git 配置
  • 支持大文件（最大 2GB）
  • 自动使用 GitHub 的 CDN
⚠️ 注意：
  • 需要文件已正确上传到 LFS 服务器
  • 免费账户有带宽限制（1GB/月）
  • 跨域可能需要配置

方案 2: 使用 GitHub Actions 自动转换

创建自动化工作流，在推送时将 LFS 文件复制到普通文件：

# .github/workflows/convert-lfs.yml name: Convert LFS to Regular Files on: push: branches: [main] jobs: convert: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 with: lfs: true - name: Copy videos to public folder run: | mkdir -p public/videos cp -r videos/*.mp4 public/videos/ - name: Deploy uses: peaceiris/actions-gh-pages@v3 with: github_token: ${{ secrets.GITHUB_TOKEN }} publish_dir: ./public
✅ 优点：
  • 完全自动化
  • LFS 文件自动转为普通文件部署
  • 保持源码仓库干净

方案 3: 使用代理服务器

创建一个简单的代理来获取 LFS 文件：

// Cloudflare Workers 示例 addEventListener('fetch', event => { event.respondWith(handleRequest(event.request)) }) async function handleRequest(request) { const url = new URL(request.url) const videoPath = url.pathname.replace('/videos/', '') const lfsUrl = `https://media.githubusercontent.com/media/QiqiTaotao666/QiqiTaotao666.github.io/main/videos/${videoPath}` const response = await fetch(lfsUrl) return new Response(response.body, { headers: { 'Content-Type': 'video/mp4', 'Access-Control-Allow-Origin': '*' } }) }

然后在网页中使用：

<video controls> <source src="https://你的worker域名.workers.dev/videos/bodian.mp4" type="video/mp4"> </video>

方案 4: 使用 jsDelivr CDN（最简单）

jsDelivr 会自动处理 LFS 文件：

<video controls> <source src="https://cdn.jsdelivr.net/gh/QiqiTaotao666/QiqiTaotao666.github.io@main/videos/bodian.mp4" type="video/mp4"> </video>
✅ 优点：
  • 完全免费
  • 全球 CDN 加速
  • 自动处理 LFS
  • 无需配置
⚠️ 限制：
  • 单文件最大 50MB
  • 需要等待 CDN 缓存（首次加载可能慢）

方案 5: 混合方案（小文件直接托管，大文件用 LFS + Media URL）

根据文件大小选择不同策略：

// 自动选择最佳 URL function getVideoUrl(filename, sizeMB) { const baseUrl = 'videos/' + filename; const lfsUrl = 'https://media.githubusercontent.com/media/QiqiTaotao666/QiqiTaotao666.github.io/main/videos/' + filename; // 小于 25MB: 使用直接路径 // 大于 25MB: 使用 LFS Media URL return sizeMB < 25 ? baseUrl : lfsUrl; } // 使用示例 const videoSrc = getVideoUrl('bodian.mp4', 1.2);
