🎥 Git LFS 视频播放实战示例

方法 1: GitHub Media URL ⭐ 推荐

直接访问 GitHub LFS 服务器上的真实文件

<video controls> <source src="https://media.githubusercontent.com/media/QiqiTaotao666/QiqiTaotao666.github.io/main/videos/bodian.mp4" type="video/mp4"> </video>
等待加载...

URL 格式：

https://media.githubusercontent.com/media/用户名/仓库名/分支名/文件路径

方法 2: jsDelivr CDN

通过全球 CDN 加速访问（支持 LFS 文件）

<video controls> <source src="https://cdn.jsdelivr.net/gh/QiqiTaotao666/QiqiTaotao666.github.io@main/videos/bodian.mp4" type="video/mp4"> </video>
等待加载...

URL 格式：

https://cdn.jsdelivr.net/gh/用户名/仓库名@分支名/文件路径

方法 3: 多源回退策略（最稳定）

提供多个备用源，浏览器会自动尝试

<video controls> <!-- 主要源: GitHub Media --> <source src="https://media.githubusercontent.com/media/.../video.mp4" type="video/mp4"> <!-- 备用源 1: jsDelivr --> <source src="https://cdn.jsdelivr.net/gh/.../video.mp4" type="video/mp4"> <!-- 备用源 2: 直接路径 --> <source src="videos/video.mp4" type="video/mp4"> </video>
等待加载...

方法 4: 使用 JavaScript 自动选择

根据文件大小自动选择最佳加载方式

<script src="lfs-video-helper.js"></script> <div id="video-container"></div> <script> const video = createRobustVideoElement('videos/bodian.mp4', 1.2); document.getElementById('video-container').appendChild(video); </script>
正在生成视频元素...

📝 使用建议

  • 小文件（< 25MB）：直接推送到仓库，使用相对路径
  • 中等文件（25-50MB）：使用 jsDelivr CDN
  • 大文件（50MB-2GB）：使用 GitHub Media URL
  • 最佳实践：使用多源回退策略，确保兼容性

🔧 快速修改现有页面

在你的 HTML 文件 <head> 标签中添加：

<script src="lfs-video-helper.js"></script>

脚本会自动为大文件视频添加备用源！
